How it works

1

Reads the transcript

Spoilerie fetches the video's subtitles and breaks them into timestamped chunks using AI embeddings.

2

Analyzes each comment

Every visible comment is matched against transcript chunks to estimate which part of the video it references.

3

Hides future spoilers

If a comment references content past your current position, it gets blurred. Click to reveal when you're ready.
