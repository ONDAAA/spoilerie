# Chrome Web Store Listing

## Name
Spoilerie — YouTube Spoiler Blocker

## Short Description (132 chars max)
Hides YouTube comments that spoil content you haven't watched yet. AI-powered, based on your current playback position.

## Detailed Description
Ever scrolled through YouTube comments while watching a video, only to accidentally read a spoiler about the ending? Spoilerie fixes that.

HOW IT WORKS
Spoilerie uses AI to understand what each comment is about by comparing it to the video's transcript. If a comment references a part of the video you haven't reached yet, it gets blurred with a spoiler warning. Click to reveal when you're ready.

FEATURES
- Automatic spoiler detection based on your current watch position
- Works on any YouTube video with subtitles/captions
- Clean blur overlay with click-to-reveal
- No setup required — install and it just works
- Toggle on/off from the popup
- Supports videos in English (more languages coming soon)

PRIVACY-FIRST
- We never access your YouTube account
- Comment text is analyzed in real-time and never stored
- No tracking, no ads, no data selling
